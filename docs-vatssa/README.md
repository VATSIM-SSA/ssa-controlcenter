# VATSSA Control Center: what we add

This is VATSIM Sub-Saharan Africa's fork of [Control Center](https://github.com/Vatsim-Scandinavia/controlcenter). Upstream's own documentation is in [`docs/`](../docs/). This folder covers only what VATSSA adds or changes, for the staff who use it and the people who maintain it.

Each page has two parts: **for staff** (what you see and can do) and **how it works** (for maintainers).

| Feature | Page |
|---|---|
| Groups: named lists of people, with managers | [groups.md](groups.md) |
| Discord role sync: the profile button, the Discord line, instant sync | [discord-sync.md](discord-sync.md) |
| Training: theory mark, Requires attention and Stalled flags | [training.md](training.md) |
| Roles and permissions | [roles.md](roles.md) |

Every change to an upstream file is listed in [`PATCHES.md`](../PATCHES.md), with the test that catches it if upstream moves underneath us. When you add a VATSSA feature, add or update its page here in the same pull request.
